Web Dev — Project 04

VM Automobiles

A prototype luxury automobile brand website — designed first in Figma, then built as a highly aesthetic, interactive web experience with a cinematic three-pane mega-menu.

Design →

The full interface was designed in Figma before implementation — hero composition, mega-menu panel hierarchy, and typography were all planned as high-fidelity mockups first.

Navigation →

3-Pane Overlay System

Clicking a nav link (Sports, Sedan, Collections, Company) opens a full-screen overlay: model categories, a dynamic submenu, and an image preview pane, all driven by one JSON menu structure.

Live Search →

An Express API endpoint searches across every category, subcategory, and model name, returning up to 10 matches for the navbar's live search suggestions.

Motion →

An animated SVG turbulence filter drives a subtle film-grain distortion, layered under sticky-header scroll transitions and smooth panel fades for a cinematic feel.

Core Features
01 Full-bleed hero with sticky, scroll-aware navbar
02 Three-pane mega-menu: models, submenu, image preview
03 Express + MongoDB backend serving menu & search data
04 Live search across categories, series, and model names
05 Animated SVG noise filter for a cinematic grain texture
06 Loading overlay and toast notifications for API state
