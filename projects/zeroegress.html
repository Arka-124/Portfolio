ZeroEgress

Air-Gapped File Utilities Running Locally on Your Machine — Convert, merge, sanitize, and process gigabyte files with zero server uploads and zero subscriptions. Features a 100% Free Web App and standalone Native Desktop binaries for Windows, macOS, Linux, and Android. Engineered by Arka Datta.

Verifiable Privacy →

Zero-Byte Outbound Telemetry

Traditional web-based converters upload proprietary NDAs and media datasets to remote cloud buckets. ZeroEgress operates strictly local: Wireshark-verified 0 B/s outbound packets, closed sockets, zero telemetry SDKs, and zero cloud retention risk.

Scale Without Bounds →

Bypass Browser WASM Limits

Web browsers crash on large files due to strict ~2GB WebAssembly heap memory ceilings. ZeroEgress Native streams directly off NVMe storage in buffered 64MB chunks, processing multi-terabyte files with <65MB RAM overhead and 0% tab crash rate.

Native Workflow →

OS Shell Right-Click Actions

Eliminates dragging files into browser dropzones. Native context menu hooks allow users to highlight 50 documents or 4K videos, right-click, and select "ZeroEgress Convert" in Windows 11 Explorer, macOS Finder Quick Actions, or Linux Nautilus.

Silicon Acceleration →

Bare-Metal GPU & Vector Units

Taps directly into bare-metal silicon: NVIDIA NVENC/NVDEC hardware transcoders, Apple Silicon M-series VideoToolbox Media Engines, and Intel QuickSync alongside AVX-512 / ARM NEON vector instructions for up to 18x faster processing speeds.

Deterministic Distribution Matrix →

Signed Binaries • Windows, macOS, Linux & Android • SHA-256 Verified

Production builds are deterministically compiled and signed across all major operating systems: Windows 64-bit (.exe setup & .msi enterprise), macOS Apple Silicon (M1–M4) and Intel (.dmg), Linux x86_64 (.AppImage universal & .deb package), and Android (.apk). Every release includes one-click SHA-256 verification and GPG signature validation for air-gapped workstations.

Developer-First Automation →

Headless CLI • Background Watch Daemon • Ed25519 Cryptographic Licensing

Bundles the standalone zeroegress executable for PowerShell, zsh, and bash scripts. Features autonomous drop-folder daemons (zeroegress watch) that automatically sanitize incoming downloads, coupled with an offline Ed25519 asymmetric cryptographic license engine requiring zero phone-home network requests.
