Problem Solved →

NMDC Bailadila Haul Roads

Monsoon fog reduces visibility to 3–5m on steep hilltop roads, costing 50–60 operational days annually and putting 100t+ dumper trucks at risk of catastrophic collisions. Truck-mounted systems fail due to extreme vehicle inertia, violent vibration, and optical blinding.

Architecture →

Leading Scout Rover

An agile autonomous scout rover navigates 15–25m ahead of heavy dumpers, acting as forward eyes with 360° LiDAR, optical camera, ultrasonic, and infrared sensor fusion to spot terrain hazards and obstacles long before the dumper reaches them.

Digital Twin →

Three.js WebGL Simulation

Interactive 3D digital twin featuring dynamic volumetric fog shaders (FogExp2), forward projector fog lights, and high-intensity pulsing rear hazard strobes engineered to provide high-visibility visual guidance for trailing dumper operators.

Active Safety →

Speed Governor & E-STOP

Uses camera detection confidence as a live proxy for fog density, automatically throttling safe recommended speeds between 0 and 35 km/h, backed by an instant emergency E-STOP broadcast interlock that halts the entire convoy when danger is detected.

Command Center Engines →

1,500-Point LiDAR Radar Scatter • Live Convoy TTC Mapping

Dual custom HTML5 2D Canvas engines rendering high-frequency sensor streams: an omnidirectional 1,500-point LiDAR radar scatter plot with real-time fog cutoff attenuation alongside an interactive live Convoy Map computing headway distance and Time-To-Collision (TTC) to eliminate tailgating risks in zero visibility.

Full-Stack & Cloud Resiliency →

Express.js • Dockerized MySQL • Zero-FOUC Theme Sync

Engineered with an Express.js backend, Google reCAPTCHA v2 validation, bcrypt auth, MySQL connection pooling with Docker, and a resilient in-memory fallback store for zero-config deployments on Render and Railway. Features a zero-FOUC Dark/Light/System theme engine that synchronizes both DOM styling and 3D Three.js lighting and shader materials in real time.
