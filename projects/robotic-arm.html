Robotics — Project 03

4-DOF Robotic Arm

A compact, 3D-printed robotic arm controlled by a miniature mimic controller — potentiometer motion on the mini controller is captured and replicated on the main arm in real time.

Objective →

Design a compact 4-DOF arm from 3D-printed parts, drive it with a potentiometer-based master–slave mimic controller, and use it for basic pick-and-place tasks — a base system extendable toward feedback control and learning-based methods.

Mimic Control →

Master–Slave Mapping

A miniature controller with one potentiometer per joint generates a 0–5V analog signal per axis. Arduino reads each (0–1023), maps it to a servo angle (0–180°), and drives the corresponding joint — no programming needed during operation.

Kinematics →

Forward and inverse kinematics are implemented in firmware — link lengths L1/L2/L3 map joint angles to XYZ gripper position and back, using the law of cosines with reachability checks for out-of-range targets.

Actuation →

MG996R servos drive the shoulder/elbow/gripper joints, with a 32kg high-torque servo for base rotation. A PCA9685 16-channel driver converts I2C commands from the Arduino Uno into precise PWM signals for each motor.

Signal Flow →

Potentiometers → Arduino Uno → PCA9685 → Servo Motors

Input Stage: potentiometers capture per-joint position. Processing: Arduino Uno reads analog signals and computes movement commands. Driver: PCA9685 converts I2C to 16-channel PWM. Output: servos execute the angular movement — SDA on A4, SCL on A5, with a common ground tying Arduino, PCA9685, and the external servo power supply together.
