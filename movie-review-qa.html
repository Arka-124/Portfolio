AI / ML — Project 01

Movie Review Q&A

A conversational agent that answers natural-language questions about films by matching them against a corpus of real movie reviews. Built during the IIT Kanpur AI/ML Internship.

Overview →

A FastAPI backend that ingests a movie review dataset, cleans and vectorizes the text, then answers free-form questions by returning the most semantically relevant review.

Matching Engine →

TF-IDF + Cosine Similarity

User queries are vectorized with scikit-learn's TF-IDF and compared against the review corpus via cosine similarity to surface the closest match.

Data Pipeline →

Missing reviews are asynchronously scraped from source URLs with aiohttp and BeautifulSoup (rotating user agents via fake-useragent), then cleaned and cached before vectorization.

Interface →

A React chat component (shadcn/ui + Tailwind) sends queries to the FastAPI /query/ endpoint and renders the matched review as a chat response.

Core Features
01 Ingests and cleans a CSV movie review dataset
02 Async-scrapes missing reviews from source URLs
03 TF-IDF vectorization with stop-word filtering
04 Cosine-similarity ranking against the corpus
05 REST endpoint (GET /query/) serving JSON
06 CORS-enabled for a decoupled React frontend
Python FastAPI Pandas Scikit-learn aiohttp BeautifulSoup React
